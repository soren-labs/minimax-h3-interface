# MiniMax H3 Colab Automation

One-command MiniMax H3 Turbo I2V generation and H3 Base second-pass repaint on a Google Colab G4. A complete batch is uploaded once and runs in one remote process with one setup and one ComfyUI startup.

On any error the script preserves the instance and writes `operator-state.json`; it never automatically stops, replaces, or restarts a failed mid-run instance.

The shutdown choice is collected before launch. A successful stop happens only after every clip, benchmark, important log, archive, and local final video has been downloaded and verified. It never reopens a fresh instance between batch items.

## Run

```bash
python3 skills/run-minimax-h3-colab/scripts/h3_colab.py \
  --steps 8 \
  --resolution 1920x1080 \
  --duration 8 \
  --prompt-file /absolute/path/prompt.txt \
  --reference-image /absolute/path/reference.png \
  --output-dir /absolute/path/results
```

The effective H3 canvas is normalized to multiples of 32 and duration to the `5 + 17*n` frame grid. For example, `1920x1080 / 8s` becomes `1920x1088 / 192 frames / 8.000s`.

For a Base repaint batch:

```bash
python3 skills/run-minimax-h3-colab/scripts/h3_colab.py \
  --mode repaint \
  --batch-manifest /absolute/path/repaint-batch.json \
  --ngc-env /absolute/path/.ngc.env \
  --resolution 1920x1088 \
  --steps 4 \
  --denoise 0.20 \
  --output-dir /absolute/path/results
```

## Production stack

- GPU: NVIDIA RTX PRO 6000 Blackwell Server Edition, 94.97 GiB
- Python 3.12, PyTorch 2.11.0+cu130, CUDA Toolkit 13.0
- Turbo LoRA: `minimax_h3_turbo_v4_step600_ema.safetensors`
- Attention: H3 memory-efficient KJ Sage patch
- Base/text models: INT8 ConvRot
- Audio: generated by H3 and decoded by the audio VAE

Repaint mode replaces the Turbo components with H3 Ref2VA Base, NVIDIA VFX Upscale 2x followed by a Lanczos center-crop resize, video/audio VAE encoding, PT AV-latent concatenation, SolAttn, `res_multistep`, and `beta`. After downloading the repainted clips, finalization stream-copies each original AAC track over the repainted H.264 video before concatenation, avoiding another audio generation. This explicit Upscale substitution is used on the Colab G4 RTX PRO 6000 Server SKU because RTX VSR cannot initialize there.

Pinned component revisions and failure recovery rules are recorded in the skill and its references.
